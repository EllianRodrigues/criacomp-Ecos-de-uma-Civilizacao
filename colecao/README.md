# Coleção

Esta pasta reúne os artefatos que fazem parte da coleção final do projeto **Ecos de uma Civilização**.

Cada pasta representa uma descoberta incorporada ao museu e deve ser lida como parte de uma sequência. A ordem é importante, pois o conhecimento sobre a civilização é construído progressivamente.

## Estrutura da coleção

Cada descoberta possui sua própria pasta, identificada por uma numeração sequencial:

```text
colecao/
├── 01-descoberta/
├── 02-descoberta/
├── 03-descoberta/
├── 04-descoberta/
├── 05-descoberta/
├── 06-descoberta/
├── 07-descoberta/
├── 08-descoberta/
└── ...
```

Dentro dela ficam os arquivos correspondentes ao artefato, como a imagem final e sua descrição:

```text
01-descoberta/
├── imagem.png
└── descricao.md
```

## Critérios para inclusão

Uma geração passa a fazer parte da coleção somente quando o grupo considera que ela está coerente com o conhecimento acumulado até aquele momento.

A descoberta deve acrescentar algo relevante sobre a civilização. Ela pode:

- complementar informações anteriores;
- aprofundar algum aspecto já apresentado;
- introduzir uma nova informação;
- contradizer, de forma coerente, uma interpretação anterior.

Resultados que não atendem a esses critérios não entram nesta pasta. Eles devem ser registrados separadamente em [`descartes/`](../descartes/).

## Ordem de leitura

As descobertas devem ser observadas em ordem numérica. Uma descoberta posterior pode depender de informações apresentadas nas anteriores; portanto, a sequência faz parte da construção narrativa do projeto.
