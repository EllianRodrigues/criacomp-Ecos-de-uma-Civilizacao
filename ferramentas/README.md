# Ferramentas

Esta pasta registra as ferramentas utilizadas durante o desenvolvimento de
**Ecos de uma Civilização**.

O objetivo é documentar quais ferramentas foram testadas ou utilizadas,
para qual finalidade foram escolhidas e quais capacidades foram importantes
para o projeto.

## O que buscamos nas ferramentas

Como o projeto será construído progressivamente, algumas capacidades podem
ser importantes durante o desenvolvimento, como:

- geração de imagens a partir de prompts;
- utilização de imagens anteriores como referência;
- manutenção de elementos consistentes entre diferentes gerações;
- possibilidade de controlar parâmetros de geração;
- acesso a seeds, quando disponível;
- geração de diferentes resultados para comparação;
- edição ou refinamento de resultados já produzidos;
- possibilidade de utilizar resultados anteriores como parte das próximas
  etapas do processo.

Nem todas essas capacidades precisam estar presentes em uma única ferramenta.
Diferentes ferramentas podem ser utilizadas em etapas diferentes.

## Ferramentas utilizadas

Conforme o projeto avançar, registraremos aqui as ferramentas que realmente
forem utilizadas.

### ChatGPT

**Uso no projeto:**

Geração da imagem da descoberta 01, **Estela das Três Correntes**, a partir de
um prompt textual detalhado.

**Capacidades utilizadas:**

Geração de imagem a partir de texto e controle, por linguagem natural, da
composição, dos materiais, do contexto arqueológico e da aparência documental.

**Limitações encontradas:**

O modelo específico, a seed e os demais parâmetros técnicos da geração não
foram apresentados na interface utilizada.

**Observações:**

O resultado selecionado representou satisfatoriamente os elementos centrais
do prompt e foi incorporado à coleção.
