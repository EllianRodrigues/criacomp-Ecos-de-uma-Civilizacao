# Descartes

Esta pasta reúne as gerações consideradas durante o desenvolvimento de **Ecos de uma Civilização**, mas que não entraram na coleção final.

O objetivo é registrar não apenas o que foi descartado, mas também os motivos pelos quais cada resultado não se encaixou no projeto.

## Estrutura da pasta

```text
descartes/
├── imagens/
├── descartes.md
└── README.md
```

### `imagens/`

Contém as imagens geradas que foram avaliadas pelo grupo, mas não foram incorporadas à coleção.

### `descartes.md`

Registra os descartes realizados ao longo do projeto e os critérios utilizados em cada decisão.

Cada registro pode indicar:

- a etapa ou descoberta em que a geração foi produzida;
- a proposta da geração;
- o motivo do descarte;
- o que não funcionou em relação ao eixo do projeto;
- observações relevantes levantadas pelo grupo.

## Critérios para descarte

Uma geração pode ser descartada quando não contribui de forma relevante para a construção da civilização ou não mantém uma relação coerente com o conhecimento acumulado até aquele momento.

Isso pode acontecer quando uma descoberta:

- não acrescenta informações relevantes;
- repete algo já estabelecido sem trazer uma nova perspectiva;
- introduz elementos sem sustentação nas descobertas anteriores;
- quebra a continuidade da coleção;
- apresenta inconsistências entre a imagem, sua descrição e o contexto construído.

## Importância dos descartes

Os descartes fazem parte do processo criativo e ajudam a tornar visíveis os critérios utilizados pelo grupo para definir o que pertence — ou não — à coleção.
