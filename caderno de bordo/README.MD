# Caderno de bordo

Esta pasta reúne os registros do processo de desenvolvimento do projeto
**Ecos de uma Civilização**.

O objetivo do caderno de bordo é acompanhar como as decisões do grupo foram
sendo construídas ao longo do projeto, registrando discussões, testes,
mudanças de direção, gerações, erros e critérios de escolha.

A ideia é preservar não apenas o resultado final, mas também o caminho que
levou até ele.

## Estrutura atual

### `2026-09-09-definicao-do-eixo.md`

Registro da discussão inicial do projeto, incluindo:

- abertura do leque de possibilidades;
- definição e refinamento do eixo;
- restrições consideradas;
- ideias rejeitadas;
- testes realizados com as skills;
- ataques feitos à proposta;
- decisões tomadas após essas discussões.

### `geracoes.md`

Registro das gerações realizadas ao longo do projeto.

Esse arquivo será atualizado conforme novas imagens e descobertas forem
produzidas, permitindo acompanhar a evolução da coleção.

### `skills.md`

Registro de como as skills utilizadas na disciplina influenciaram o processo
criativo do grupo.

Para cada skill, será registrado:

- qual skill foi utilizada;
- quando foi utilizada;
- o que ela mudou no projeto;
- onde ela ajudou ou atrapalhou o processo.

## Como este caderno será utilizado

Os registros desta pasta serão feitos ao longo do desenvolvimento do projeto,
e não apenas ao final.

Sempre que houver uma decisão relevante, uma mudança no eixo, uma geração
importante, um descarte significativo ou alguma alteração no processo, isso
poderá ser registrado aqui.

Dessa forma, o caderno funciona como um histórico do desenvolvimento de
**Ecos de uma Civilização**.
