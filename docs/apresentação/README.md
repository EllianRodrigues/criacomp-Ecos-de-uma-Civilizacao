Esta pasta reúne os materiais utilizados na apresentação do projeto
**Ecos de uma Civilização**.

Podem ser armazenados aqui:

- slides;
- roteiro da apresentação;
- imagens selecionadas para demonstração;
- comparações entre resultados;
- exemplos de descartes;
- diagramas do processo;
- outros materiais utilizados durante a apresentação.
